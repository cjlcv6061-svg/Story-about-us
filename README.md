# 《幻影組曲》台詞小精靈 — 部署與改台詞說明

## 檔案
- `index.html` — 工具本體（不含劇本，台詞由 script.json 載入）
- `script.json` — 劇本台詞與角色分派（23 場），**你日後要改的就是這個**
- `角色對照表.md` — 給你自己核對用，不必上傳

`index.html` 和 `script.json` 必須放在**同一個資料夾**。

---

## 一、放上 GitHub Pages（一次性設定，約 5 分鐘）

1. 在 GitHub 開一個新 repo（可設為 Public）。**要跟《離地，到着》分開一個 repo。**
2. 把 `index.html` 和 `script.json` 一起上傳（拖進網頁上傳即可）。
3. 進 repo 的 **Settings → Pages**。
4. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 Save。
5. 等一兩分鐘，頁面頂部會出現網址，像：
   `https://你的帳號.github.io/repo名稱/`
6. 把這條網址發給劇組，用手機或電腦瀏覽器打開就能用。

> 兩個劇的進度紀錄不會互相覆蓋：這個版本的 localStorage 前綴是 `ps_`，《離地，到着》是 `ld_`。

## 二、日後改台詞（不必重發任何檔案）

1. 在 GitHub 上點開 `script.json`，按右上角鉛筆圖示 ✏️ 直接編輯。
2. 改完按 **Commit changes**。
3. 劇組把頁面**重新整理**（下拉刷新），就看到新台詞了。

### script.json 格式

整個檔案是一個陣列，每一場長這樣：

```json
{
  "no": "第四場B",
  "name": "家庭",
  "sub": "熄滅",
  "act": "第二幕",
  "place": "睡房",
  "roles": {
    "妻": { "n": "妻子", "g": "f", "a": ["Judy"] },
    "夫": { "n": "丈夫", "g": "m", "a": ["Don"] }
  },
  "lines": [
    { "s": "妻", "t": "又靜晒喇……" },
    { "s": "夫", "t": "乾淨台詞", "r": "(坐起身)含舞台指示的原文", "seg": ["第一節…", "第二節…"] },
    { "d": "（這是一段獨立的舞台指示，不會被朗讀）" }
  ]
}
```

**`roles`（這個劇特有，最重要）**
一人分飾多角，所以每一場都要說明「台詞標籤是誰演的」：

- key = 劇本裡的台詞標籤（`妻`、`編12`、`舞女1`、`四人`…），要跟 `lines` 裡的 `s` 完全一樣。
- `n` = 角色全名，顯示在測驗提示與朗讀角色名。
- `g` = 性別，`m` 男 / `f` 女 / `n` 中性（旁白、編劇、BB）。只影響朗讀音色。
- `a` = 演員陣列。**改分派就是改這裡**。
  - 一個人演：`["Judy"]`
  - 齊聲／合說（如「四人」「眾舞女」「高低」）：`["Connie","Jenny","Sophie","Sindy"]`
  - 未定：`[]`（工具會顯示「（待定）」，該角台詞不會算入任何人）

**`lines`**
- `s` = 台詞標籤，必須在同一場的 `roles` 裡有定義。
- `t` = 台詞本文（朗讀與背誦用，不含括號指示）。
- `r` = 選填。含舞台指示的完整原文，開「顯示舞台指示」時顯示。
- `seg` = 選填。長獨白的分節陣列，測驗模式會一節一節練、各自記分。不需要就整個刪掉。
- `d` = 獨立舞台指示行（只有 `d`，沒有 `s`/`t`），不朗讀。

**其他欄位**：`no` 場次代號（導覽列與成績用，必須唯一）、`name` 場名、`sub` 段落名、`act` 幕別、`place` 景。

### 常見改動速查
| 要做的事 | 改哪裡 |
|---|---|
| 換演員 | 該場 `roles` 裡那個角色的 `a` |
| 加一個演員一齊講 | 把名字加進 `a` 陣列 |
| 改台詞 | 該行的 `t`（有 `r` 的話一起改，保持一致） |
| 改角色顯示名 | 該場 `roles` 裡的 `n` |
| 朗讀音色太高／太低 | 該場 `roles` 裡的 `g` 改 `m`／`f`／`n` |
| 長獨白唔想分節 | 刪掉該行的 `seg` |

### 改的時候注意
- 引號 `"` 要用半形英文引號，台詞內若要用引號請用「」或『』。
- 每個物件之間用逗號 `,` 分隔，最後一個不要多餘逗號。
- 演員名字要**逐個字一模一樣**（`Suki L` 和 `Suki  L` 是兩個人）。
- 改完若頁面顯示「未能載入劇本」，多半是 JSON 格式錯（漏逗號／引號），把剛改的地方檢查一下。可貼到 jsonlint.com 驗一下。

## 三、本機測試（選用）

直接雙擊 index.html 會因瀏覽器安全限制讀不到 script.json（會顯示「未能載入劇本」）。要本機測試就在資料夾開終端機跑：

```
python3 -m http.server
```

再開 `http://localhost:8000`。

## 四、給 Claude Code 的話（如果日後叫它改）

**只准做被要求的改動。禁止：**
- 重構、優化、整理 `index.html`
- 把 `index.html` 拆成多個檔案（CSS/JS 分家）
- 重新編碼、重新格式化、美化 `script.json`（它是刻意壓縮成單行的）
- 改動未被提及的功能

改完請用 `node --check` 驗 JS 語法，用 `python3 -m json.tool` 驗 JSON。

## 這個版本的外觀／功能（STORY ABOUT US）

**跟《離地，到着》版最大的分別：以「演員」為單位，不是以「角色」為單位。**
《幻影組曲》一人分飾多角，所以進場撳返自己個名，全劇所有你有份的角色台詞都會一次過隱藏。

**外觀**
- 「劇場夜色・稜鏡碎片」深色主題（夜藍底、舞台燈琥珀＋冷月藍點綴），永遠深色。
- 進場頁：碎片 logo + 24 位演員緊湊格，每人一個專屬色（黃金角色相分散，24 人都分得開）與台詞句數。
- 每句台詞左側印章顯示**角色標籤**，底色是**演員的專屬色**；齊聲台詞用漸層帶出多個演員。
- 頂部標題列可隨捲動收起，騰出讀台詞空間。

**練習功能**
- 「輪到你」虛線提示卡：點一下回想、再揭曉台詞。
- 揭曉後可標「記得／唔記得」自評，頂部有「記得 N/M」進度條（分演員記錄）。
- 朗讀對戲：讀對手台詞、輪到你留白；可選「接話模式」「顯示我詞」「讀角色名」「提示音」。
- 測驗模式：輸入台詞對答案，同音字算對、助語詞嚴格。28 句長獨白已自動分節，一節一節練。
- 朗讀音色依**角色性別**分（男聲／女聲／中性），同場不同角色再加音高微調區分。
- 循環播放（可指定句號範圍）、接續下一場、只練未掌握。
- **角色對照**：逐場列出「台詞標籤 → 角色 → 演員」，可切「只看我有份嘅場」，撳場名直接跳去該場。
- 字級調整、進度記錄存在本機（各演員分開計算）、可匯出 Markdown 報告。

**未包含**
- 四首歌的歌詞（Season Of Love、我們都是這樣長大的、娛樂人生、Season Of Love Reprise）屬第三方版權作品，工具內只保留歌曲提示位。若要加歌單，請自行在 `script.json` 相應的 `d` 行後補上。
